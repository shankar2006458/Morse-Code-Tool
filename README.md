# Morse Code Tool

A modern and professional Morse Code Generator & Decoder built with **HTML, Tailwind CSS, and Vanilla JavaScript**. Convert text to Morse code, decode Morse back to text, visualize signals, and play authentic Morse audio tones.

## Features

### Text → Morse

* Real-time text to Morse conversion
* Supports letters, numbers, and common symbols
* Visual Morse representation using dots and dashes
* Copy Morse output with one click
* Adjustable playback speed (WPM)
* Adjustable audio tone frequency
* Morse audio playback

### Morse → Text

* Real-time Morse decoding
* Supports manual Morse input
* Dedicated dot, dash, space, and separator buttons
* Copy decoded text instantly

### User Experience

* Premium dark theme interface
* Fully responsive design
* Desktop and mobile navigation
* Smooth animations and transitions
* Keyboard shortcuts
* Character counter
* Morse reference chart
* Modern typography and visual effects

## How to Use

### Encode Text

1. Open **Text → Morse**
2. Type your message
3. Morse code is generated instantly
4. Copy or play the output

### Decode Morse

1. Open **Morse → Text**
2. Enter Morse code
3. Decoded text appears instantly
4. Copy the result if needed

## Morse Input Rules

| Symbol | Meaning          |
| ------ | ---------------- |
| ·      | Dot              |
| —      | Dash             |
| Space  | Letter Separator |
| //     | Word Separator   |

Example:

```text
HELLO

···· · ·—·· ·—·· ———
```
